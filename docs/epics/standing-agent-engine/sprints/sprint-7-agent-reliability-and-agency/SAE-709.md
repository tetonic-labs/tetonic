# SAE-709: Durable agent checkpoints and restart isolation

Status: Planned
Owner: Tetonic Engine (lokai repository)
Priority: P1
Milestone: M3
Estimate: 8 relative points (planning estimate, not a delivery commitment)
Dependencies: SAE-706, SAE-707, SAE-708

## Outcome and implementation

Persist agent memory, working intentions, event cursors and configuration identity using versioned atomic checkpoints. Separate agent continuity from world session identity. Define restore policy when world epoch/snapshot differs.

Prevent old pending mutations from replaying on restart. Record checkpoint and restore events; support a fresh-agent mode for controlled experiments. Use existing persistence abstractions where suitable after an implementation audit.

## Acceptance criteria

- [ ] Restart restores the selected agent's memory and intentions without importing another agent's state.
- [ ] Restoring against an incompatible world snapshot fails clearly or applies an explicit reset policy.
- [ ] A crash between action execution and acknowledgement cannot duplicate the action on recovery.
- [ ] Corrupt/incompatible checkpoints produce actionable errors and preserve the last valid checkpoint.

## Validation

Crash-boundary and compatibility tests with coordinated world snapshots.
