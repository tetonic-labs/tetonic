# SAE-711: Audited experimental internal-state interventions

Status: Planned
Owner: Tetonic Engine (lokai repository)
Priority: P2
Milestone: M4
Estimate: 5 relative points (planning estimate, not a delivery commitment)
Dependencies: SAE-706, SAE-707, SAE-709

## Outcome and implementation

Define an explicitly enabled experimental interface to alter permitted agent-owned state, distinct from external suggestions and objective assignment. Start with schema-defined preferences or working-state fields; do not promise controllable emotions from text alone.

Validate target, allowed fields, operation and revision. Record before/after state, origin and timestamp. Keep operator provenance in the audit log even if testing how an internally presented thought affects behavior. Support restoration from an experiment checkpoint.

## Acceptance criteria

- [ ] An ordinary suggestion cannot silently mutate memory, preferences or objectives.
- [ ] An enabled internal-state edit has a traceable diff and affects only the selected agent.
- [ ] Unsupported fields and stale revisions fail without partial mutation.
- [ ] Disabling the experimental capability prevents these edits while normal communication still works.

## Validation

API isolation, schema validation, stale revision and checkpoint restoration tests.

## Delivery notes

Keep changes local. Record implementation files, commands/results, migration behavior and remaining limitations here when completed. Do not mark complete from a successful model utterance alone. Resolve dependency ticket IDs through the sprint indexes in each repository.
