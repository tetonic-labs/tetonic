# SAE-704: Structured decisions and bounded failure recovery

Status: In progress
Owner: Tetonic Engine (lokai repository)
Priority: P0
Milestone: M1
Estimate: 5 relative points (planning estimate, not a delivery commitment)
Dependencies: SAE-702, SAE-703

## Outcome and implementation

Validate decision envelopes and advertised action schemas before transport. Use structured generation when the provider supports it, retaining local validation. Classify malformed output, output truncation, provider failure, timeout and unsupported action separately.

Allow a configurable bounded recovery attempt with corrected budget or validation feedback. Never resend an identical known-oversized prompt. Do not replay a possibly executed mutating action as an inference retry; transport retries use action idempotency. Preserve failed raw responses in bounded trace capture.

## Acceptance criteria

- [ ] Malformed or truncated output submits no world action.
- [ ] A recoverable malformed response can be repaired within the configured retry limit.
- [ ] Exhausted recovery produces a terminal failed-decision event and remains interruptible.
- [ ] A simulated transport timeout after execution does not cause duplicate world mutation.

## Validation

Fake-provider sequences for success, malformed JSON, length stop, timeout and persistent error; transport ambiguous-result fixture.

## Delivery notes

Keep changes local. Record implementation files, commands/results, migration behavior and remaining limitations here when completed. Do not mark complete from a successful model utterance alone. Resolve dependency ticket IDs through the sprint indexes in each repository.


## Implementation checkpoint — 2026-09-24

Length-terminated decisions are explicitly rejected before action parsing, even if their text happens to be valid JSON. Essential context overflow submits no request or action. Added a fake-provider regression for both cases. Remaining: advertised action schema validation, bounded corrective retries and ambiguous transport outcome handling. Recovery is not yet implemented.
