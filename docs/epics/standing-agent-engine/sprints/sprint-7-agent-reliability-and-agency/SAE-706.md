## Outcome and implementation

Replace the fixed recent-intent list as the main continuity mechanism with typed agent-owned memories: observation, action attempt, outcome, heard statement, own speech, and self-authored intention. Store provenance, time, scope and confidence/verification state separately from content.

Retrieve within a budget using recency and relevance; deduplicate repeated speech. Persist only what the agent was exposed to. Current observations supersede stale facts without rewriting history. Village supplies events, not an authoritative record of the agent's beliefs.

## Acceptance criteria

- [ ] Repeated speech cannot become a directly observed world fact.
- [ ] Successful acceptance and later failure remain distinguishable in recalled experience.
- [ ] A relevant older outcome can be retrieved despite many intervening decorative observations.
- [ ] Memory retrieval for agent A never returns agent B's private input or unseen world state.

## Validation

Deterministic memory fixtures for contradiction, repetition, relevance and scope isolation. Evaluate summaries against source event IDs.

## Agent-continuity checkpoint — 2026-09-24

Implemented an initial agent-owned ExperienceMemory in the configured brain: 64 retained events, 256 recent deduplication IDs, retrieval of four recent non-self-utterance records not already in the current event page. Categories distinguish heard statements, own utterances, external suggestions, world outcomes and other world events. Records preserve source event metadata. Object observations retain their separate direct-observation memory. Goal changes clear intention context but retain evidence; world/agent changes clear scope.

Validation: provenance, deduplication, private scope and objective-change tests; fake-provider test verifies heard statements remain labeled and do not become observations. Remaining: relevance-based retrieval beyond recency, durable storage, salience and contradiction/summary evaluation. This is bounded working experience, not complete autobiographical memory.
