# SAE-710: Multiple local residents and inference fairness

Status: Planned
Owner: Tetonic Engine (lokai repository)
Priority: P1
Milestone: M3
Estimate: 8 relative points (planning estimate, not a delivery commitment)
Dependencies: SAE-705, SAE-708

## Outcome and implementation

Configure and host at least three real local agents through the existing runtime abstractions. Isolate cognition, memory, event queues, trace identity and controls. Add bounded inference concurrency and fair scheduling appropriate to one local inference server.

Expose per-agent start, stop and health without requiring distributed deployment. Audit existing fleet machinery and reuse it rather than building a competing supervisor.

## Acceptance criteria

- [ ] Three real residents operate with separate inputs and decisions; no simulated stand-ins.
- [ ] One slow or failed resident does not corrupt or indefinitely starve the others.
- [ ] Per-agent stop affects only that agent; world E-stop still blocks all relevant mutation.
- [ ] Queue latency and inference concurrency are measured and bounded by configuration.

## Validation

Multi-agent fake-provider load test plus local live run with three independently configured residents.

Keep changes local. Record implementation files, commands/results, migration behavior and remaining limitations here when completed. Do not mark complete from a successful model utterance alone. Resolve dependency ticket IDs through the sprint indexes in each repository.
