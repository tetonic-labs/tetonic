# SAE-707: Persistent self-authored intentions and working state

Status: Planned
Owner: Tetonic Engine (lokai repository)
Priority: P1
Milestone: M2
Estimate: 8 relative points (planning estimate, not a delivery commitment)
Dependencies: SAE-706

## Outcome and implementation

Add an optional configurable cognition capability for a resident to maintain its own intention, next step, assumptions, progress evidence and revision reason. Keep assigned objectives separate from self-authored intentions. Intentions are hypotheses/plans, never proof of execution.

Carry working state across decisions and reconcile it with world outcomes. Permit revision, abandonment and intentional waiting. Avoid injecting a default exploration quest or any Village-specific target into engine code.

## Acceptance criteria

- [ ] An intention can span multiple navigation/interaction decisions without being reissued by an operator.
- [ ] A blocked action can cause an explicit revision or abandonment grounded in feedback.
- [ ] Open mode permits no intention and legitimate waiting; it does not force random activity.
- [ ] The capability works with a synthetic adapter unrelated to the Village.

## Validation

Scripted-provider tests for continuity and revision; live qualitative runs record outcomes without requiring a prescribed story or target.

## Delivery notes

Keep changes local. Record implementation files, commands/results, migration behavior and remaining limitations here when completed. Do not mark complete from a successful model utterance alone. Resolve dependency ticket IDs through the sprint indexes in each repository.
