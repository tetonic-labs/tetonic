
## Project Management Structure
- Do not use a top-level sprints folder. Enforced by `QG-DOCS-001` (`lokai-arch-gate`).
- For any epics we make, create an <epic_name> folder.
- Inside the <epic_name> folder, create a sprints folder.
- Any tickets for each sprint must go inside the specific sprint folder they are associated with (e.g., docs/epics/<epic_name>/sprints/<sprint_name>/<ticket_name>.md).
